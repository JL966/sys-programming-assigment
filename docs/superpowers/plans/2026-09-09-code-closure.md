# 真实验收代码闭环实施计划

目标：完成 PC 与固件的可执行协议闭环，产出 HEX；实板验收另行开展。
设计依据：../specs/2026-09-09-real-acceptance-code-completion-design.md。

- [x] 协议客户端：严格匹配响应、有限同序号重试、断线取消、串口资源释放。
- [x] 共享契约：配置 CRC、记录头、结果记录、板号身份页。
- [x] 板端：可执行的会话、配置、计划、记录、租约及清理；保留有限内存。
- [x] 适配器边界：人工确认可出记录；所有尚未取得实测适配器证据的自动项明确返回 EVIDENCE_GAP。
- [x] PC 编排：三角色绑定、实时结果、持久化后释放、恢复提示与来源隔离。
- [x] 集成测试：真实 24 字节帧经虚拟三板与 PC 客户端联测，覆盖异常、权限和人工决定。
- [x] 页面：真实连接、配置、人工操作、历史与导出，保留现有风格。
- [x] 安全边界：人工项目有限租约、档案能力不匹配 BLOCKED、来源切换和旧异步运行隔离。
- [ ] 交付：软件回归、Keil 编译、HEX 校验、更新能力文档并提交。

每个行为使用针对性的测试，自动测试不作为实板结论。工程内修改，不进行烧录。

当前唯一构建阻塞：2026-09-09 本机 DUT/REF 新源码已生成 HEX；CTRL 新源码编译为 0 error，但 BL51 对该工程单独报 L250，旧 CTRL HEX 未覆盖。三份新 HEX 未齐前不得生成新发布清单。
