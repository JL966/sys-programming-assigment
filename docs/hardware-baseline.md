## 写入前安全确认

- [ ] 拍摄 U6 芯片丝印并确认实际 EEPROM 型号/容量。
- [ ] 明确 `0x10..0x1F` 是否允许作为 scratch；不允许则 T05/T06 为 BLOCKED。
- [ ] 读取并保存 scratch 原值和 CRC，保存文件能在另一台电脑打开。
- [ ] 确认 PC 已持久化备份后，才在当前会话打开写入许可。
- [ ] 每次测试结束均读回原值；不一致时标记 `RESTORE_REQUIRED` 并停止后续写入。

## 降级决策

- 第三块板或第三条 USB 不可用：采用双板/单 USB，报告降低独立见证与故障定位等级。
- EEPROM 型号或数据归属未确认：保留只读检查，禁止写入/掉电测试。
- 485 三节点接线不稳定：先回到两板 1200 bps，不能同时推进传感器集成。
- 没有超声波新鲜度/失败标志：稳定重复值只能 `INCONCLUSIVE`。
