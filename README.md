# 焊后无忧——STC学习板焊接故障诊断系统

一次烧录，按页面提示检查23项板载及扩展功能。无需逐个烧录测试程序；大多数项目只用一块板，红外和RS485才需要第二块辅助板。

## 准备什么

- Windows电脑，安装 Node.js，使用 Edge 或 Chrome 浏览器。
- STC-B学习板、USB数据线；磁铁、遮挡物和有线耳机。
- 红外测试需第二块学习板；RS485另需接线。缺少器材可跳过。

仓库根目录附有学校发放的 `stc-isp-v6.88F.exe`，可用于将诊断HEX烧录到学习板；已经安装STC-ISP的用户可继续使用原软件。

## 从零开始

1. 下载仓库并解压到普通文件夹，不要直接在ZIP内运行。
2. 用 STC-ISP 烧录 `firmware/diagnostic/output/AcceptanceDiagnostic.hex`，芯片选 STC15F2K60S2，运行时钟 **11.0592MHz**。所有板烧录同一个HEX。
3. 关闭下载工具和串口助手，双击 **启动学习板诊断.cmd**，网页会自动打开。
4. 点击“连接被测板”，选择对应CH340串口。板上显示 `01`；辅助板连接后显示 `02`。
5. 点击“一键整轮”，按照网页的1、2、3步骤操作；准备好后再点“开始”。
6. 声光项目请按实际看到、听到的现象选择“正常”或“异常”。无法辨认时按异常处理并重新测试；其余项目由程序读取证据判断。
7. 没有器材就点击“跳过此项”。结束后可导出HTML/JSON，也可选择某项“单项测试”复测。
8. 17～23项更换器件时，按提示拔掉被测板USB、断电接线，再点“重新连接并继续”。仍是同一轮记录，不需要重烧HEX。

网页版本为2.4.0，诊断固件版本为2.3.0。运行期间关闭页面后，可点击“恢复未完成轮次”；已完成结果保留，当前未完成项目从准备步骤重新检测。

## 能检查什么

复位、USB/UART1、LED、数码管、K1/K2/K3、五向键、蜂鸣器、温度、光照、霍尔、振动、RTC、EEPROM、FM/耳机、红外、RS485。

扩展项目还包括：SM步进电机、超声波、直流电机、电子秤、电子尺、电子转角测量器、RFID读卡器。

请使用课程提供的原配器件与适配线束。电机不可直接接IO；通用3.3V裸RFID模块不可直接接5V。RFID检查ISO14443A卡的只读卡号响应（4/7/10字节UID），不写卡。电机由用户确认真实机械动作，指令接受不能证明电机正常。

红外：两板USB接同一电脑，红外头相对约10～20厘米，无需485线。RS485：断电后按丝印连接A-A、B-B、参考地，不接VCC，再接USB。

页面顶部的“认识学习板”可查看板载功能位置、课程元器件总图和7种扩展器件。点击学习板上的半透明标签可直接查看简短说明和关联检测项；该模块不连接硬件，也不影响诊断结果。

## 怎样看结果

- 绿色“正常”：本轮检查通过。
- 红色“异常”：点击展开查看本轮证据对应的可能原因、建议和报修提示。
- 橙黄色“未测试”：主动跳过、缺少设备或断连；不算正常，展开后只显示一行说明。

“只显示异常和未测试”可隐藏正常项。存在异常时显示“发现异常”；只有未测试时显示“未完成”；所有项目通过才显示“本轮通过”。记录保存在当前浏览器本地，重要结果请导出备份。

## 常见问题

- 无法连接：关闭占用串口的软件，检查USB数据线和CH340驱动，确认烧录的是上述HEX。
- 网页不更新：先结束测试，再按 Ctrl+F5 刷新或重新双击启动脚本。
- 有限时间内不操作：按键、传感器和人工确认项目都会超时异常；只有主动跳过、缺少必要设备或连接中断才记为未测试。
- EEPROM测试期间不要断电或复位；程序会备份、写入测试值、校验并恢复。

本工具判断模块功能链路，不保证定位具体坏焊点。RTC仅验证通电走时，不验证电池断电保时；EEPROM抽测一个地址；温度用于响应检查，不是精密测温仪。RS485仍需具备接线后实测确认。

## 源码

统一固件工程位于 `firmware/diagnostic`，使用课程BSP和Keil C51；网页源码位于 `web`。普通用户直接使用仓库中的HEX，无需自行编译。

需要重新编译固件时，可在PowerShell中执行 `firmware/diagnostic/build.ps1`；默认Keil安装目录为 `D:\Keil`。
